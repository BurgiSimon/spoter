# Security policy

Please **do not** open public issues for security problems.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/BurgiSimon/spoter/security/advisories/new).
Include steps to reproduce and the impact you expect. You will get an answer within a few days,
and a fix is coordinated with you before anything is disclosed.

Supported version: the latest release on `main`.
